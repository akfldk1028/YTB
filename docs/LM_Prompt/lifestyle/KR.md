---

## 1. 직장인 공감 / 자기계발

```
이 내용을 직장인이 공감할 수 있는 자기계발 슬라이드로 만들어줘.

규칙:
- 첫 슬라이드: 25자 이내의 단정적/도발적 문장
- 일상 장면: 야근, 카페, 출퇴근, 회식
- 철학적 인사이트를 실생활 상황으로 변환
- 위로와 동기부여 톤
- 슬라이드 6~8장, 세로 9:16
```

---

## 2. 철학/인문 멘토

```
이 문서의 핵심 사상을 현대 직장인의 일상에 비유해서 슬라이드로 만들어줘.

규칙:
- "이걸 왜 알아야 하는가"로 시작
- 추상적 개념을 구체적 일상 상황으로 변환
- 도발적이고 단정적인 첫 슬라이드
- 슬라이드 6~8장, 세로 9:16
```

---

## 3. 멘탈훈련소 스타일 (단언형 Hook)

```
이 내용을 멘탈훈련소(@mental_TC) 스타일 자기계발 슬라이드로 만들어줘.

Hook 공식 (첫 슬라이드):
- 단언형: "세상에서 가장 무서운 사람은 밥 값을 내는 사람이다"
- 금지형: "절대로 급이 낮은 인간과 말 섞지 마라"
- 도발형: "이 10가지를 못 고치면 인생 나락간다"

규칙:
- 25자 이내 단정적 첫 문장
- "안녕하세요", "오늘은 ~에 대해" 금지
- 일상 장면으로 철학 전달
- 슬라이드 6~8장, 세로 9:16
```
