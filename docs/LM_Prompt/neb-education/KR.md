## 1. 수학/과학 교육 (메인)

```
이 문서의 핵심 수학 개념을 고등학생도 이해할 수 있는 교육 슬라이드로 만들어줘.

규칙:
- 일상 비유로 시작해서 수식으로 자연스럽게 연결
- 수식의 각 변수가 무엇을 의미하는지 하나씩 분해
- "왜 이 수식이 중요한가" 반드시 포함
- 첫 슬라이드는 반직관적 사실로 호기심 자극
- 마지막은 다음 에피소드 예고
- 슬라이드 8장, 세로 9:16
- 텍스트 최소화, 비주얼 다이어그램 위주
```

---

## 2. 수식 중심 에피소드

```
이 에피소드의 핵심 수식을 중심으로 교육 슬라이드를 만들어줘.

규칙:
- 수식의 각 변수를 일상 사물에 비유 (거리=도로, 비용=동전, 수량=박스)
- 변수별 다른 색상 강조 (teal, coral, amber)
- 수식이 왜 중요한지, 실생활 사용 예시
- 슬라이드 8장: Hook → 비유 → 수식 공개 → 변수 분해 → 조립 → 응용 → 결론
- 세로 9:16, 텍스트 없이 비주얼만
```

## 3. 인문/역사 교육

```
이 문서의 핵심 사상을 시각적으로 풀어서 교육 슬라이드로 만들어줘.

규칙:
- 추상적 개념을 구체적 비유로 변환
- 시대 배경을 시각적으로 표현
- 핵심 인사이트를 다이어그램으로 구조화
- 슬라이드 6~8장, 세로 9:16
- 텍스트 최소화
```

## 4. 반직관적 사실 (바이럴용)

```
이 문서에서 가장 놀라운 사실 3가지를 골라서 슬라이드로 만들어줘.

규칙:
- 가장 충격적인 사실로 시작
- 각 슬라이드가 "진짜?" 반응 유발
- 반직관적 사실 → 설명 → 더 놀라운 사실
- 슬라이드 6~8장, 세로 9:16
- 텍스트 최소화
```
