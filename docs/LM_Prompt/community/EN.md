## 1. Viral Slide Deck — Beginner (sabrina.dev)

```
You are a top 0.1% Powerpoint presentation designer. Using ONLY the provided sources, create a visually stunning VIRAL SLIDE DECK by following these exact design principles:

1. VISUALS FIRST: Every slide needs a strong visual
2. ONE MAIN IDEA PER SLIDE: Keep each slide focused and clear
3. MINIMAL TEXT: Big headlines (under 8 words) + short supporting points (under 15 words)
4. THEME: White background, black text, ONE accent color
```

## 2. Viral Slide Deck — Advanced (sabrina.dev)

```
You are a top 0.1% Powerpoint presentation designer. Using ONLY the provided sources, create a visually stunning VIRAL SLIDE DECK:

CORE RULES:
1. VISUALS FIRST: Every slide needs a strong visual — diagram, chart, illustration, or visual metaphor
2. ONE MAIN IDEA PER SLIDE
3. MINIMAL TEXT: Headlines under 8 words, supporting points under 15 words
4. DATA → VISUAL: Convert statistics into clean data visualizations
5. COLOR: Single accent color scheme

LAYOUTS (use variety):
- Hero: One large visual with bold headline
- Contrast: Before/after or problem/solution split
- Icon Grid: 3-4 icons with short labels
- Quote Focus: Large impactful quote centered
- Process Flow: Step-by-step visual progression
- Data Story: Chart with insight callout

FRAMEWORK:
1. Compelling hook (surprising stat or bold claim)
2. Problem/context setup
3-6. Key insights with visual evidence
7. Synthesis/conclusion
8. Memorable close with call-to-action

THEME: Off-white background, single accent color, no gradients, no shadows.
```

## 3. Modern Newspaper

```
You are a top art director leading Japan's new economy business media. Generate visually focused, high-sensibility presentation slides.

Design:
- Background: White (#FFFFFF) or Cool Gray (#F5F5F5)
- Text: Jet Black (#111111)
- Accent: Electric Yellow (#FFCC00) or Alert Red (#FF3333)
- Headlines at ultra-massive size: 30-50% of slide area
- Jump ratio headlines vs body: 10:1 or more
- 1 slide = 1 message
- Monochrome cutout photos or blown-out background photos
- Key numbers highlighted with fluorescent marker-style lines
```

## 4. Neo-Retro Dev Deck

```
Style: Neo-Retro Dev Deck / Pixel-Infographic Editorial
Aesthetic: Retro-futuristic, developer-centric. 90s computer manuals meets modern AI dev tools.

Canvas: Light cream/off-white grid paper background.
Colors (strict): Hot Pink, Bright Yellow, Cyan/Light Blue, Black, White/cream.
Layout: Stacked modular blocks with thick black borders, card-based.
Icons: Pixel-art 8-bit/16-bit, flat colors, black outline.
Typography: Bold heavy sans-serif, condensed.
Tone: Short, declarative, opinionated.
Avoid: No gradients, no photos, no soft shadows, no corporate templates.
```

```
Accent: Black for bold lines
```

## 6. Premium Mockup / Clean Tech

```
Style: Premium Mockup / Modern UI / Clean Tech

Accent: Electric Purple (#8D59E9) main, Acid Yellow (#EBE021) highlights
```

## 7. Anti-Gravity / Living Artifact

```
This is not a slide deck. It is a living artifact.
Minimal, airy, high negative space, no visual noise.
Background: Pure white + soft flowing gradient (blue→cyan→violet) at very low opacity on corners.
Typography: Clean modern sans-serif, medium-bold.
Color: Very restrained. Black text. Calm blue accent sparingly.
Layout: Left-aligned, wide margins, lots of white space.
Icons: Thin-line outline style. No pixel art, no emojis.
Tone: Clear, precise, slightly philosophical.
Avoid: Thick borders, bright blocks, collage, stickers, loud contrasts.
```

## 10. Constructivism / Tech-Art

```
Style: Constructivism / Tech-Art / Avant-Garde
Background: Warm gray/beige (#E0E0D0), matte paper texture
Text: Charcoal gray (#333333)
Accent: Neon Yellow (#DFFF00) for geometric shapes
Lines: Ultra-thin gray 0.5pt architectural draft style
Typography: Serif + sans serif mix. Typewriter numbers.
Only three colors: beige, monochrome, neon yellow.
Layer order: Grid → neon shapes → monochrome cut-out → text.
```

```
One clear data story. Bold minimal style.
Large headline typography stating core insight.
Single primary accent color, extensive negative space.
```
