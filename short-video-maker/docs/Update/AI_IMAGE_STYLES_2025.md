## 🔥 바이럴 트렌드 (TikTok/Instagram)

### 1. Y2K Chrome Aesthetic
```
Y2K aesthetic, chrome metallic textures, iridescent holographic elements,
early 2000s pop culture, plastic shiny surfaces, sparkles and glitter,
futuristic retro fashion, bold neon colors, tech-inspired backgrounds
```
**특징**: 2000년대 초반 노스탤지어, 크롬/메탈릭 질감, 홀로그램
**인기 이유**: 레트로 감성 + Z세대 향수

### 2. AI Figurine / Limited Edition Drops
```
Collectible figurine in transparent acrylic display case, miniature 3D character,
toy photography style, product shot lighting, limited edition packaging,
detailed sculpt, soft studio lighting, blurred background
```
**특징**: 피규어 박스 안에 캐릭터가 들어있는 형태
**인기 이유**: 팬덤 문화 + 굿즈 콜렉팅 트렌드

### 3. Chibi Anime Style
```
Chibi anime character, big head small body ratio, exaggerated cuteness,
large sparkly eyes, pastel color palette, kawaii aesthetic,
simple clean background, soft cel shading
```
**특징**: 2등신~3등신 비율, 과장된 귀여움
**인기 이유**: 밈 제작, 감정 표현에 최적

### 4. Cute Face Pinch / Chubby Cheek Effect
```
Adorable baby-like portrait, pinched chubby cheeks, soft rosy skin,
innocent expression, soft diffused lighting, dreamy pastel background,
ultra cute transformation, doll-like features
```
**특징**: 볼살 꼬집는 듯한 귀여운 변환
**인기 이유**: 2025년 바이럴 필터 트렌드

### 5. 3D Claymation Style
```
Claymation style, stop-motion animation aesthetic, soft clay textures,
handmade imperfections, warm studio lighting, miniature set design,
Aardman-inspired, tactile materials, playful characters
```
**특징**: 점토 애니메이션 질감
**인기 이유**: 수제 느낌의 따뜻함

## 🎨 아티스틱 스타일

### 6. Neo-Classical Sci-Fi Fusion
```
Classical oil painting style meets futuristic technology, renaissance composition,
dramatic chiaroscuro lighting, subject wearing cyberpunk armor,
ornate gold frames with holographic elements, baroque meets sci-fi
```
**특징**: 고전 회화 + SF 요소 믹스
**인기 이유**: 예술성 + 신선한 대비

### 7. Pop Surrealism (Lowbrow Art)
```
Pop surrealism art style, whimsical and slightly grotesque,
playful irony, vibrant saturated colors, dreamlike impossible scenes,
Mark Ryden inspired, big-eyed characters, candy-colored nightmare
```
**특징**: 귀엽지만 기이한 분위기
**인기 이유**: NFT/소셜미디어에서 주목도 높음

### 8. Cyberpunk Neon
```
Cyberpunk aesthetic, neon-lit urban environment, rain-soaked streets,
holographic advertisements, pink and cyan color scheme,
Blade Runner inspired, high contrast, moody atmosphere
```
**특징**: 네온 불빛, 비 오는 도시, 어두운 분위기
**인기 이유**: 게임/영화 영향, 지속적 인기

### 9. Doodlecore
```
Doodlecore aesthetic, hand-drawn sketch style, notebook paper texture,
ballpoint pen illustrations, casual imperfect lines, margin doodles,
playful annotations, school notebook vibes
```
**특징**: 낙서 스타일, 손그림 느낌
**인기 이유**: 2025년 소셜미디어 신흥 트렌드

## 📸 사진/시네마틱 스타일

### 10. Editorial Fashion Photography
```
High fashion editorial photography, Vogue magazine style,
dramatic studio lighting, shallow depth of field, 35mm lens,
luxurious textures, glamorous pose, dreamy ethereal glow
```
**특징**: 패션 매거진 화보 스타일
**용도**: 제품/인물 고급 이미지

### 11. Analog Film Vintage
```
Vintage analog film photography, Kodak Portra 400 color science,
film grain texture, slightly faded colors, warm nostalgic tones,
1970s aesthetic, light leaks, soft focus edges
```
**특징**: 필름 카메라 감성
**용도**: 감성적 분위기 연출

### 12. Cinematic Wide Shot

```
Cinematic wide shot, anamorphic lens flare, 2.39:1 aspect ratio,
dramatic color grading, volumetric fog, golden hour lighting,
movie still quality, epic scale, atmospheric depth
```
**특징**: 영화 스틸컷 느낌
**용도**: 스토리텔링 장면

## 🛠️ 프롬프트 작성 팁 (2025)

### DO ✅
- 자연어로 장면 묘사 (카메라맨에게 설명하듯)
- 조명, 카메라 설정, 분위기 구체적 명시
- 구조화된 문장 사용

### DON'T ❌
- ~~키워드 나열 (epic, cinematic, ultra-realistic...)~~
- ~~과도한 형용사 중첩~~
- ~~모호한 지시어~~

### 예시
```
❌ BAD: "epic cinematic ultra realistic beautiful amazing cat"

✅ GOOD: "A fluffy orange cat sitting on a vintage armchair,
soft window light casting warm shadows, shot with 50mm lens,
shallow depth of field, cozy living room background,
Kodak Portra color grading"
```
