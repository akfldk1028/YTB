## 📌 개요 / Overview

>[!abstract] TL;DR
>**캐릭터 이미지 2개** + **시나리오 텍스트** → **자동으로 꽁냥꽁냥 영상 생성**
>
>Cat A + Cat B images + Story script → Auto-generated cute interaction video

```
┌─────────────────────────────────────────────────────────────────┐
│                    PIPELINE OVERVIEW                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [Cat A Image] + [Cat B Image] + [Story Script]                 │
│                         ↓                                        │
│              GPT-4o / Claude                                     │
│         (시나리오 → 장면별 프롬프트)                              │
│                         ↓                                        │
│            Nano Banana Pro                                       │
│    (각 장면의 First Frame + Last Frame 생성)                     │
│         ※ 첫 이미지를 참조로 계속 사용 = 일관성!                  │
│                         ↓                                        │
│               Veo 3.1                                            │
│      (First + Last Frame → 영상 보간)                            │
│                         ↓                                        │
│           Video Editor                                           │
│         (클립들 조합 + 배경음악)                                  │
│                         ↓                                        │
│         🎬 완성된 스토리 영상!                                    │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 🔑 핵심 트릭 / Key Tricks

>[!important] 성공의 핵심 3가지
>
>### 1. 첫 이미지를 계속 참조로 재사용
>새 장면마다 처음부터 생성 ❌
>기존 이미지를 참조로 넣고 변경사항만 요청 ✅
>→ **캐릭터 일관성 자동 유지**
>
>### 2. First + Last Frame 기법
>Veo 3.1에 시작/끝 프레임 지정
>→ **그 사이를 자연스럽게 채워줌**
>
>### 3. GPT/Claude가 시나리오 → 프롬프트 자동 변환
>스토리 텍스트를 시네마틱 프롬프트로 쪼개줌
>→ **매번 프롬프트 안 써도 됨**

## 📜 시나리오 예시 / Story Example

```markdown
# story/scenario.md

## 제목: 첫 만남 (First Meeting)

### Scene 1: 발견 (Discovery)
딸기가 창가에서 햇살을 받으며 낮잠을 자고 있다.
까미가 조심스럽게 방에 들어와 딸기를 발견한다.

### Scene 2: 호기심 (Curiosity)
까미가 멀리서 딸기를 지켜본다.
딸기가 눈을 뜨고 까미를 발견한다.

### Scene 3: 다가감 (Approach)
까미가 일어나서 딸기에게 천천히 다가간다.
딸기는 약간 긴장하지만 도망가지 않는다.

### Scene 4: 인사 (Greeting)
두 고양이가 코를 맞대고 인사한다.
서로의 냄새를 맡는다.

### Scene 5: 친해짐 (Bonding)
까미가 딸기의 머리를 핥아준다.
딸기가 눈을 감고 편안해한다.

### Scene 6: 낮잠 (Nap Together)
두 고양이가 함께 창가에서 웅크리고 잠든다.
햇살이 두 고양이를 비춘다.
```

## 🤖 Claude CLI 명령어 / Commands

```bash

Confirm you understand their appearances and personalities."
```

### Step 1: 시나리오 → 장면 프롬프트 변환

```bash
claude "Read story/scenario.md and convert each scene into:

1. FIRST FRAME prompt (장면 시작 상태)
2. LAST FRAME prompt (장면 끝 상태)
3. VIDEO MOTION prompt (Veo용 움직임 설명)

Format as JSON. Include character identity lock prompts.
Save to story/scene_prompts.json"
```

### Step 2: 프레임 생성 (Nano Banana Pro)

```bash
claude "Using scene_prompts.json, generate frames for each scene.

For EACH scene:
1. Upload both cat reference images to Gemini
2. Generate FIRST FRAME using the first_frame prompt
3. Use the generated first frame AS REFERENCE for last_frame
4. Generate LAST FRAME (only change pose/expression, keep identity)

Save frames to frames/scene_XX/

CRITICAL: Always include identity lock prompts!
CRITICAL: Use first frame as reference for last frame generation!"
```

### Step 3: 영상 생성 (Veo 3.1)

```bash
claude "Using the generated frames, create videos with Veo 3.1.

For EACH scene:
1. Upload first_frame.png as 'image' (first frame)
2. Upload last_frame.png as 'lastFrame' (last frame)
3. Use video_motion prompt for the transition
4. Set aspect_ratio: 16:9, duration: 6 seconds

API call pattern:
- model: 'veo-3.1-generate-preview'
- generationType: 'FIRST_AND_LAST_FRAMES_2_VIDEO'
- Include reference images for character consistency

Save videos to videos/scene_XX.mp4"
```

### Step 4: 최종 영상 조합

```bash
claude "Combine all scene videos into final output.

1. Order clips by scene_id
2. Add 0.5s crossfade transitions between scenes
3. Add background music (cozy/warm mood)
4. Export to output/final_video.mp4

Optional: Add title card at start, credits at end"
```

## 🎥 Veo 3.1 API 호출 패턴

### Python 예시

```python
from google import genai
from google.genai import types

client = genai.Client()

# Scene 1 영상 생성
operation = client.models.generate_videos(
    model="veo-3.1-generate-preview",
    prompt="""
    Gentle dolly in toward the window.
    Orange tabby cat (Nabi) sleeps peacefully.
    Gray cat (Kongi) enters from right, ears perking up.
    Soft warm lighting. Natural cat movements.
    """,
    image=first_frame_bytes,  # 첫 번째 프레임
    config=types.GenerateVideosConfig(
        last_frame=types.Image(
            image_bytes=last_frame_bytes,  # 마지막 프레임
            mime_type="image/png"
        ),
        aspect_ratio="16:9",
        duration_seconds=6,
        # 참조 이미지로 캐릭터 일관성 강화
        reference_images=[
            cat_a_reference,
            cat_b_reference
        ]
    ),
)

# 결과 대기 및 저장
result = operation.result()
video_url = result.generated_videos[0].video_uri
```

## 🎬 Veo 시네마틱 프롬프트 가이드

### 카메라 움직임 / Camera Movements

| 한글 | English | 사용 상황 |

| 천천히 다가감 | Slow dolly in | 감정적 순간, 집중 |
| 뒤로 물러남 | Dolly out / Pull back | 상황 전체 보여주기 |

| 따라가기 | Tracking shot | 움직이는 캐릭터 따라감 |
| 위로 올라감 | Crane up | 장면 마무리, 전환 |
| 고정 | Static | 대화, 관찰 장면 |

| 장면 분위기 | Keywords |
|------------|----------|
| 평화로운 | peaceful, serene, calm, cozy |

| 호기심 | curious, attentive, alert |
| 다정한 | affectionate, tender, warm |

## 🚨 트러블슈팅 / Troubleshooting

### 캐릭터가 장면마다 다르게 보임

```
문제: 고양이 무늬나 색이 바뀜
해결:
1. Identity Lock 프롬프트를 더 구체적으로
2. 첫 프레임을 반드시 참조 이미지로 업로드
3. "MAINTAIN EXACT same appearance" 강조
4. 참조 이미지 품질 확인 (선명하고 잘 보이는지)
```

### 두 캐릭터가 합쳐지거나 구분 안 됨

```
문제: 두 고양이가 하나로 보임
해결:
1. 위치를 명확히 지정 (left side, right side)
2. 각 캐릭터를 별도로 설명
3. "Two distinct cats" 명시
4. 처음엔 한 캐릭터씩 따로 생성 후 합성
```

### Veo 영상이 부자연스러움

```
문제: 움직임이 어색하거나 끊김
해결:
1. First/Last frame 차이를 너무 크게 하지 말 것
2. 한 동작씩만 요청 (여러 동작 X)
3. 카메라 움직임을 단순하게
4. 6초 이하로 짧게 생성
```

### 일관성 드리프트 (시간이 지날수록 달라짐)

```
문제: 장면이 진행될수록 캐릭터가 변함
해결:
1. 매 장면마다 원본 참조 이미지 다시 업로드
2. 중간에 "reset" 역할로 원본 이미지 한번 더 참조
3. 이전 장면의 best frame을 다음 장면 참조로 사용
```
